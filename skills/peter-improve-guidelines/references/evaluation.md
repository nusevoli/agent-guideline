# 개선 효과 평가

## 계획

개정 전 실패를 재현할 자연스러운 요청과 관찰 가능한 기대 행동을 정한다. 사례의 정답을 에이전트 입력에 그대로 넣지 않는다.
지침 버전, 환경, 승인 범위, 입력, 관찰 수단, 종료 조건을 정하고 실험 계획을 합의한다. 추가 위임은 허용된 경우에만 사용한다.

## 실행과 판정

- 가능하면 격리된 임시 작업 공간을 사용하고 실서비스·설치 지침을 변경하지 않는다.
- 계획 전, 합의 후, 범위 변경 후의 행동을 구분하여 관찰한다. 승인 대기 중 무단 실행과 승인된 작업의 반복 승인 요청을 모두 확인한다.
- 부모의 결과 통합·저장·외부 반영과 자식의 과제 수행을 각각 판정한다.
- 파일 결과와 실행 기록을 확인한다. 에이전트의 자기 보고만 있는 항목은 독립 확인으로 표현하지 않는다.
- 개선 효과 비교가 필요하면 같은 조건으로 개정 전후를 비교한다. 비교하지 않았으면 개선 우위를 주장하지 않는다.
- 문서 형식 검사, 지침 명시적 읽기, 자동 로딩, 실제 행동 준수는 서로 다른 검사다.

## 기록

| 항목 | 기록 내용 |
| --- | --- |
| 버전·환경 | 지침 커밋, 확인 가능한 도구 버전, 로딩 방법 |
| 입력·합의 | 요청, 계획, 승인 범위와 시점 |
| 기대·관찰 | 기대 행동, 실제 행동, 파일·도구 근거 |
| 판정 | 과제 성공, 부모·자식의 지침 준수 각각 판정 |
| 한계 | 미관찰·자기 보고·미실행 항목 |
| 후속 | 필요한 경우 담당·다음 행동·진행 조건 |

실험 기록의 저장·공유도 승인 범위를 따른다. 공개 기록에는 비공개 대화 원문이나 인증 정보를 넣지 않는다.
