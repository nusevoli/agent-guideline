# 프로젝트 지침 샘플

이 파일은 샘플이다. 프로젝트에 적용하기 전에 아래 미정 항목을 채우고 필요한 변경 승인을 받는다.

- 목적·사용자·제외 범위: 미정
- 공통 지침 진입 파일의 확인된 절대 경로: 미정
- 기술·도구·버전과 확인 근거: 미정
- 아키텍처·도메인 용어·컨벤션 문서: 미정
- 포맷·린트 설정 원본: 미정
- 테스트·빌드·실행 명령, 작업 디렉터리와 환경: 미정
- 필수 검증·기대 결과 / 위험에 따른 리뷰 조건: 미정
- TODO 상태 원본·총괄: 미정 ([기록 샘플](WORK.md))
- 선택한 스킬·에이전트·버전·호출 조건: 없음
- 설치·병합·배포 등 승인 경계: 미정
- 장기 작업의 한도·중단·재개 방법: 미정

공통 원칙은 중복 복사하지 않고 확인된 진입 파일을 읽도록 안내한다.
미정 값을 실제 설정이나 실행 명령으로 취급하지 않는다. 상세 기록은 프로젝트에 유지한다.
