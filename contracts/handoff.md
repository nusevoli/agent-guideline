# 위임과 결과 인계 양식

## 전달

- 작업 ID / 목적 / 전체 작업에서의 위치:
- 확정 조건 / 적용 지침과 읽을 경로:
- 담당 범위·파일 / 제외 범위:
- 읽기·변경·실행·추가 위임 권한:
- 입력 자료 / 선행 결과:
- 요구 결과 / 완료 조건 / 검증 방법:
- 공유 파일 보존·충돌 방지 방식:
- 상태 기록 담당 / 결과 반환 위치:

## 반환

- 상태(완료·검증 필요·응답 대기·차단):
- 실제 변경·산출물 / 커밋:
- 검증 근거 / 미검증과 영향:
- 남은 결정·차단 / 다음 담당·행동:

작업자의 완료 보고는 총괄의 최종 완료 판정을 대신하지 않는다.
