# 작업 기록 양식

작은 작업은 필요한 필드만 사용한다. 상태 원본 위치와 총괄을 먼저 지정한다.

- 상태 원본 / 총괄:
- 작업 ID / 상위 목적:
- 요구 결과 / 제외 범위:
- 담당 / 변경 대상:
- 선행 작업·조건:
- 승인된 행동·근거 / 별도 승인 대상:
- 상태 / 이전 상태 / 변경 이유·시각:
- 완료 조건 / 검증 방법:
- 검증 근거 링크 / 대상 커밋·변경 상태:
- 차단 원인 또는 필요한 사용자 응답 유형:
- 다음 행동 / 담당 / 진행 조건:
- 실행 ID / 측정 가능한 한도 / 사용량(미측정이면 명시):
- 결정 이유 / 취소·재개 이력:

## 예시

| ID | 작업 | 상태 | 완료 조건 | 다음 행동 |
| --- | --- | --- | --- | --- |
| T1 | 변경안 PR 작성 | 완료 | 승인 범위의 diff와 검사 결과가 있는 PR 생성·확인 | T2 판단 |
| T2 | 병합·로컬 반영 | 사용자 응답 대기 | 승인된 커밋 병합·동기화·연결 확인 | 사용자 병합·반영 승인 후 AI 실행 |

예시 상태는 실제 프로젝트의 완료 주장으로 사용하지 않는다.
