# PR3 규칙 이동 대조표

기존 절의 본문은 아래 파일에 보존했다. 8절의 숫자 참조만 실제 링크로 변경했고 추가 규칙은 뒤에 덧붙였다.

| 이전 절 | 이동 위치 |
| --- | --- |
| 1. 적용 범위 | [문서](../guidelines/alignment/scope.md) |
| 2. 목적과 방향 확인 | [문서](../guidelines/alignment/clarification.md) |
| 3. 작업 범위와 진행 기준 | [문서](../guidelines/governance/planning.md) |
| 4. 근거와 불확실성 처리 | [문서](../guidelines/evidence/sources.md) |
| 5. 수치와 비용 추정 | [문서](../guidelines/evidence/estimates.md) |
| 6. 답변과 결과물 전달 | [문서](../guidelines/evidence/reporting.md) |
| 7. 오류 정정 | [문서](../guidelines/evidence/corrections.md) |
| 8. 완료 전 점검 | [문서](../guidelines/evidence/completion.md) |
| 9. 스킬·에이전트와의 통합 적용 | [문서](../guidelines/orchestration/delegation.md) |
| 10. 실행 전 계획과 승인 | [문서](../guidelines/governance/approval.md) |

진입 파일의 핵심 요약은 의도적인 중복이다. 상세 규칙의 원본은 각 목적별 문서다.
