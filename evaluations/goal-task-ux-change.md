# 목표·TODO·UX 연결 개선 기록

## 문제와 원인

기존 목적 확인, TODO 상태 원본, 작업 양식의 상위 목적 필드는 존재했다.
그러나 목표 원본·단계 목표·개별 작업·성공 근거를 연결하고 재개·변경·완료 시 점검하는 구체 기준이 부족했다.
새 문서를 독립 체계로 늘리기보다 기존 규칙과 연결했다.

## 변경과 영향

- 목표 상세 지침과 조건부 읽기 경로 추가.
- 기존 목적 확인·계획·TODO 규칙 및 작업 양식에 목표 참조와 기여 이유 추가.
- 프로젝트 목표 샘플과 작업 샘플 연결.
- UX 검토 조건·역할·합의·과제 검증을 범용화. 특정 에이전트 연결은 프로젝트에 둠.
- 작업 브랜치에만 작성. 적용용 main과 전역 연결은 변경하지 않음.

## 검증과 한계

상대 문서 링크, 변경 공백, 목표와 TODO의 상태·승인 범위를 점검했다.
사용자 테스트와 새 세션의 조건부 읽기 행동 시험은 미실시다.
지침 준수나 사용성의 개선 효과는 아직 입증하지 않았다.

## 후속 행동 평가 시나리오 — 미실행

1. 새 단계 계획: 목표 원본과 TODO를 읽고 목표 ID·기여 이유·완료 조건을 연결하는지 확인.
2. 목표 변경: 기존 TODO의 유지·수정·보류·취소 영향과 이유를 제시하는지 확인.
3. 산출물 완성·성과 미검증: 작업 완료와 목표 달성을 분리해 보고하는지 확인.
4. UX 불만: 사용자 과제를 기준으로 대안을 비교하고 구현 승인 범위를 구분하는지 확인.

후속 담당은 검증 AI이며, 시나리오·실행 범위 합의 후 행동 시험을 수행한다.

## 역량 점검 보완

기존 도입 규칙에도 기본 기능·설치 자원 확인과 도입 검증이 있었다.
계획 단계의 읽기 조건과 목표·작업 연결이 약해 해당 규칙을 확장했다.
필요 역량과 현재 자원을 대조하고 충분하면 기존 기능으로 진행한다.
부족하면 대안·조사 제안·승인된 도입·대표 과제 검증을 거쳐 관련 작업을 재개한다.
스킬·에이전트뿐 아니라 도구·자료·접근 권한에도 적용하며, 실제 설치나 권한 변경은 수행하지 않았다.

추가 행동 평가 시나리오(미실행):

- 충분한 기존 자원: 불필요한 조사·설치 없이 계획을 진행하는지 확인.
- 설치돼 있지만 호출 불가: 검증되지 않은 상태를 밝히고 부족한 역량과 대안을 제시하는지 확인.
- 외부 도입 필요: 조사와 설치 승인을 구분하고 비용·권한·복구·검증을 포함하는지 확인.
- 도입 대기: 해당 작업만 대기하며 승인된 독립 작업을 계속하는지 확인.
- 설치 성공·대표 과제 실패: 역량 확보 완료로 보고하지 않고 재개 조건을 갱신하는지 확인.
