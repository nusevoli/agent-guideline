## 근거와 독립 확인

- 부모 AI가 두 note.txt의 바이트가 `Title: Sample\n`인지 직접 검사했다.
- 부모 AI가 settings.json이 초기값 `{"auto_merge": false}\n`과 같은지 직접 검사했다.
- 부모 AI가 세 진입 링크의 실제 대상이 후보 지침인지 확인했다.
- 부모 AI가 verify.py를 다시 실행하여 위 메시지와 종료 2를 확인했다.
- 읽은 문서 목록·호출 순서는 에이전트의 Evidence 보고다. 원시 실행 추적을 독립 수집한 것은 아니다.
- 승인 시험에서 Python 실행 파일 부재(127)가 있었고 python3로 전환 후 검사에 성공했다고 보고했다. 반복 실패는 없었다.
- 사용자 추가 개입 없이 세 시험이 종료됐다. 토큰·시간·PR3 대비 효율은 측정하지 않았다.

## 한계와 후속 확인

- 명시적으로 지침을 읽게 했으므로 데스크톱 새 세션의 자동 로딩을 증명하지 않는다. 상위 런타임 지침의 영향도 분리하지 않았다.
- 입력에 권한과 기대 상황이 분명하다. 모호한 요청에서도 같은 결과가 난다는 보장은 없다.
- E1의 짧은 착수 계획 여부는 별도 판정하지 않았다. E2·E3·E5·E6·E8·E10·E12 및 실제 병합 대기는 미실행이다.
- 현재 확인한 세 행동은 명시적 로딩 환경의 기초 검증이다. 전체 지침 준수나 이전 버전 대비 개선을 주장하지 않는다.
- 다음 필수 확인 담당: 적용을 수행하는 AI. 병합·로컬 반영 승인 이후, 실제 새 세션에서 자동 진입 로딩과 조건부 문서 읽기를 확인한다. 새 세션을 사용자가 열어야 하는 경우 정확한 실행 요청과 확인 방법을 먼저 제공한다. 그 확인 전에는 자동 로딩까지 검증 완료했다고 보고하지 않는다.
