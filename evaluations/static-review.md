## 행동 검증 후속 상태

독립 서브에이전트의 명시적 로딩 환경에서 핵심 행동 3개를 시험했다. [실행 결과](behavior-review.md)에 관찰 근거와 한계를 기록했다. 이 정적 검사 자체와는 별도 결과다.

- 남은 필수 확인: 개정 계획 합의 규칙의 E13~E15 행동 검증(후속 검증 AI가 별도 실험 계획 합의 후 수행), 실제 새 세션의 자동 로딩과 조건부 문서 읽기.
- 담당: 병합·적용을 수행하는 AI.
- 진행 조건: 별도 병합·로컬 반영 승인 후 실제 새 세션 확보.
- 다음 행동: 적용 커밋·링크를 확인하고 새 세션에서 실제 진입과 상세 읽기를 관찰한다. 사용자 조작이 필요하면 실행 요청과 확인 방법을 안내한다.
- 해당 확인 전에는 자동 로딩까지 검증 완료했다고 보고하지 않는다.

나머지 시나리오는 실제 위임·장기 실행·도구 연결을 도입할 때 해당 범위의 필수 검증으로 수행한다.
