# 도입·교체 기록 양식

- 프로젝트 / 상위 목표·관련 작업 링크 / 필요한 역량:
- 기존 자원·호출 가능성·검증 근거 / 부족·미확인 역량과 영향 / 설치 없이 가능한 대안:
- 후보·출처 / 확인 날짜 / 버전·커밋:
- 내용·사용 경험 근거 / 미확인 주장:
- 라이선스·고지 / 의존 도구·권한 / 비용·미확인 사항:
- 적용 범위·경로 / 변경 설정 / 제외 범위:
- 입력·출력 / 호출 조건 / 공통 상태 매핑:
- 지원 기능 / 미지원·실패 시 대안:
- 기존 지침·도구 충돌 / 조정 내용:
- 권장안·장단점·영향 / 사용자 선택·승인:
- 설치·연결·활성화 결과 / 대표 과제·기대 결과·실제 검증 근거:
- 관련 작업의 재개 조건 / 실패 시 대안·독립적으로 계속할 작업:
- 원본 대비 수정 / 업데이트 방식:
- 중단·제거·기록 이전·복구 절차:

검토 중인 후보를 승인되거나 활성화된 도구로 표시하지 않는다.
