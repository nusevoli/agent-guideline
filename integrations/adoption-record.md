- 후보·출처 / 확인 날짜 / 버전·커밋:
- 내용·사용 경험 근거 / 미확인 주장:
- 라이선스·고지 / 의존 도구·권한:
- 적용 범위·경로 / 변경 설정 / 제외 범위:
- 입력·출력 / 호출 조건 / 공통 상태 매핑:
- 지원 기능 / 미지원·실패 시 대안:
- 기존 지침·도구 충돌 / 조정 내용:
- 권장안·장단점·영향 / 사용자 선택·승인:
- 설치·활성화 결과 / 실제 동작 검증:
- 원본 대비 수정 / 업데이트 방식:
- 중단·제거·기록 이전·복구 절차:
